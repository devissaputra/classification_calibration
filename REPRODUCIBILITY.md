# Reproducibility Protocol

## Environment

Use Python 3.11 or newer.

    python -m venv .venv
    source .venv/bin/activate
    pip install -r requirements.txt
    PYTHONPATH=. pytest -q
    PYTHONPATH=. python src/run_experiment.py

## Frozen primary design

- UCI dataset ID: 222
- primary seed: 42
- repeated seeds: 13, 29, 42, 73, 101
- test fraction: 0.20
- logistic regression max iterations: 4000
- primary calibration CV: 5 folds
- calibration CV sensitivity: 3, 5, 10 folds
- primary ECE: 10 equal-width bins
- ECE sensitivity: 5, 10, 20 bins
- paired split-level bootstrap: 5,000 resamples

## Generated evidence

A successful full run regenerates:

- results/metrics.json
- results/repeated_runs.csv
- results/sensitivity_cv.csv
- results/sensitivity_ece.csv
- results/ablation.csv
- results/error_analysis.csv
- results/summary.md
- results/figures/calibration_curve.png
- results/figures/roc_curve.png
- results/figures/repeated_brier.png
- paper/results.md

## Network boundary

Tests are offline. The empirical runner requires network access because it retrieves dataset 222 through ucimlrepo. This keeps CI deterministic while preserving a direct, documented route to the original UCI source.

## Evidence policy

Only outputs generated by the current runner count as empirical evidence. Do not copy values from the repository's earlier demonstration dataset or from a previous protocol.
