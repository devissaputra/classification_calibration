# Reproducibility Protocol

## Environment

Use Python 3.11 or newer.

    python -m venv .venv
    source .venv/bin/activate
    pip install -r requirements.txt
    PYTHONPATH=. pytest -q
    PYTHONPATH=. python src/run_experiment.py

## Frozen full-study defaults

- dataset: UCI Bank Marketing, dataset 222
- frozen bank-full.csv SHA-256: d1513ec63b385506f7cfce9f2c5caa9fe99e7ba4e8c3fa264b3aaf0f849ed32d
- canonical file: bank-full.csv from the official UCI archive
- primary seed: 42
- repeated seeds: 13, 29, 42, 73, 101
- test fraction: 0.20
- stratified splitting: enabled
- logistic regression max iterations: 4000
- primary calibration CV: 5 folds
- calibration CV sensitivity: 3, 5, 10 folds
- primary ECE: 10 equal-width bins
- ECE sensitivity: 5, 10, 20 bins
- paired split-level bootstrap: 4,000 resamples

## Generated evidence

A successful full run regenerates:

- results/metrics.json
- results/repeated_runs.csv
- results/summary.md
- results/figures/calibration_curve.png
- results/figures/roc_curve.png
- results/figures/precision_recall_curve.png
- paper/results.md
- paper/results.tex

The full sensitivity, ablation, uncertainty, error-analysis, and environment records are embedded in results/metrics.json.

## Data retrieval

The runner downloads the official UCI archive directly and extracts bank-full.csv, then caches that CSV under data/cache. A local bank-full.csv can instead be supplied with the --data-path option. In both cases the bytes must match the frozen expected SHA-256 before modeling begins; the recorded result manifest repeats the accepted hash for auditability.

## CI boundary

Unit tests are offline and do not contact UCI. The separate empirical workflow performs the real-data run and commits regenerated evidence artifacts.

## Quick mode

The --quick flag runs only the primary split and skips expensive sensitivity analyses. Quick-mode output is useful for smoke testing but does not satisfy the full Research Bundle evidence contract.

## Evidence policy

Only outputs generated by the current full runner count as empirical evidence. Do not reuse values from the repository's earlier demonstration dataset or from quick mode as final study results.
