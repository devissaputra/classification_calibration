# Reproducibility Protocol

## Environment
Use Python 3.11+.

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
pytest -q
python src/run_experiment.py
```

## Frozen defaults
- UCI dataset ID: 222
- random seed: 42
- test fraction: 0.20
- logistic regression: max_iter=4000
- calibration CV: 5 folds
- ECE: 10 equal-width bins

## Output
The empirical runner writes `results/metrics.json`. That file records dataset ID, sample count, prevalence, split sizes, seed, model metrics and software versions.

## Network boundary
Unit tests are offline and do not contact UCI. The empirical runner requires network access for the dataset download. This separation keeps CI deterministic while keeping the research path tied to the documented real source.

## Result policy
Do not copy metrics from the previous breast-cancer demonstration into a paper or README. Only metrics generated by the current UCI Bank Marketing runner count as bundle evidence.
