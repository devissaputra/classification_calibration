# Reproducing the Experiment

From the repository root:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python src/run_experiment.py
```

On Windows, activate with `.venv\Scripts\activate`.

The script loads the dataset directly from scikit-learn, uses a stratified 75/25 split with `random_state=42`, fits the scaling and logistic-regression pipeline, and writes the metrics to `results/metrics.json`.

The calibration and ROC plots are also regenerated by the script.

Small differences can appear if package versions change, so record your Python and scikit-learn versions when comparing runs.
