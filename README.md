# Classification and Probability Calibration

![Project overview](assets/01_cover.svg)

I built this project to look at a simple question that is easy to miss in classification work: a model can rank cases well and still give poor probability estimates.

The experiment uses logistic regression on the Wisconsin Diagnostic Breast Cancer dataset. I evaluate both classification performance and the quality of the predicted probabilities.

## Data

I use scikit-learn's Wisconsin Diagnostic Breast Cancer dataset.

- 569 samples
- 30 numerical features
- binary target
- 75% training, 25% test
- stratified split with random state 42

More detail is in [DATA.md](DATA.md).

## How the experiment works

![Processing pipeline](assets/02_data_pipeline.svg)

The code does the following:

1. loads the dataset;
2. creates a stratified train/test split;
3. standardizes the features using a pipeline;
4. fits logistic regression;
5. predicts class probabilities on the test set;
6. converts probabilities to class predictions using a 0.5 threshold;
7. measures accuracy, ROC-AUC, and Brier score.

The main script is [src/run_experiment.py](src/run_experiment.py).

## Why calibration matters

![Probability view](assets/03_data_or_model.svg)

ROC-AUC tells me how well the model ranks positive and negative cases. The Brier score asks a different question: are the probabilities themselves close to the observed outcomes?

A probability of 0.80 should mean something more useful than simply "the model is confident." That is why I included both discrimination and probability quality in the same experiment.

## Results

![Evaluation summary](assets/04_evaluation_or_results.svg)

The recorded run produced:

| Metric | Result |
|---|---:|
| Accuracy | 0.9860 |
| ROC-AUC | 0.9977 |
| Brier score | 0.0181 |

These values come from `results/metrics.json`, generated by the experiment script.

## What I learned

The model separates the two classes very well on this split. The low Brier score is also encouraging, but I would not treat one hold-out split as enough evidence that the probabilities are reliably calibrated in every setting.

A better follow-up would use repeated validation, confidence intervals, and an explicit comparison of calibration methods such as Platt scaling and isotonic regression.

## Run it

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python src/run_experiment.py
```

On Windows, activate the environment with `.venv\Scripts\activate`.
